Quick Start

Create your first AI agent with financial capabilities in minutes. Our SDK makes it simple to integrate secure payment functionality into your agents.

# Install the t54 SDK npm install @t54/sdk # Create an agent with financial capabilities import { T54Client } from '@t54/sdk'; const t54 = new T54Client({ apiKey: 'your-api-key' }); # Create agent account const agent = await t54.agents.create({ name: 'shopping-assistant', spendingLimit: 1000, // USD allowedMerchants: ['amazon', 'uber'] }); # Make a payment const payment = await agent.pay({ recipient: 'merchant-id', amount: 25.99, purpose: 'Coffee order for user' });
